# Runtime requirements

Install the [complete package](installation.md). The native registrars only
register skill files. Skill procedures control when to call tools or execute a
script. Installation grants no authority for a skill action.

Use Git and an authenticated `gh` session with access to the fork and the
GitHub.com target. This also applies to read-only reconnaissance. These
procedures support GitHub.com. Keep the shared contribution handoff and
runtime-trust references with each skill.
